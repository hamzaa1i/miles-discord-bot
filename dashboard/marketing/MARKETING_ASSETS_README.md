# marketing assets — what each file is for ✦

all assets are generated by
`scripts/generate_marketing_assets.py` (PIL, veloura palette, no
external services) and are safe to commit. re-run the script any time
to regenerate them deterministically.

> **the four "preview" images are stylized mockups, not real
> screenshots.** they are pixel-consistent with the product but
> generated, not captured — perfect for launch day, and easy to replace
> with real captures later (see "replacing mockups with real
> screenshots" below).

## file guide

| file | size | where it goes |
|---|---|---|
| `aurelia-logo-512.png` | 512×512 | top.gg / bot list avatar, github social card |
| `aurelia-logo-1024.png` | 1024×1024 | hi-res listings, press kits |
| `aurelia-icon-transparent.png` | 1024×1024 | transparent star icon — overlays, server icon, watermarks |
| `aurelia-banner-1920x1080.png` | 1920×1080 | github repo banner, generic listings |
| `aurelia-banner-2000x1000.png` | 2000×1000 | discord server banner, og fallback |
| `aurelia-features-collage.png` | 1600×1000 | listings that want a feature grid image |
| `aurelia-dashboard-preview.png` | 1600×900 | "dashboard" screenshot slot on listings |
| `aurelia-chat-preview.png` | 1200×630 | "ai chat" screenshot slot |
| `aurelia-welcome-preview.png` | 1200×630 | "welcome cards" screenshot slot |
| `aurelia-mod-preview.png` | 1200×630 | "moderation" screenshot slot |

the open-graph image for the website itself is NOT in this folder — it
lives at `dashboard/public/og-image.png` (1200×630) because it must be
served by the site.

## bot list descriptions

- `description-short.md` — ≤100 chars, top.gg tagline
- `description-medium.md` — ≤500 chars, listing summary
- `description-long.md` — ≤2000 chars, full listing body
- `tags.md` — tags, categories, one-line feature list

## replacing the mockup previews with real screenshots (later)

1. open the live product:
   `https://veloura-aurelia.vercel.app`
2. capture:
   - dashboard preview → `/login` → a server overview (1600×900,
     browser at 100% zoom, os dark mode)
   - chat preview → discord window showing an @aurelia conversation
     (blur user tags)
   - welcome preview → the welcome module's live preview panel
   - mod preview → the warnings page with 2-3 cases
3. keep the exact filenames above and drop them into this folder
4. commit — listings and the readme gallery pick them up by name

## regenerating

```bash
python scripts/generate_marketing_assets.py
```

deterministic output — same input, same bytes. fonts used: liberation
serif (headings, playfair-adjacent) + liberation sans (body,
inter-adjacent), the closest metric equivalents available offline.
